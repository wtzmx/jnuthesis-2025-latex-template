Jiangnan University Thesis Template

江南大学研究生学位论文 LaTeX 模板

适配《江南大学研究生学位论文要求及格式规范（2025 年修订）》，面向硕士学位论文、博士学位论文和毕业论文写作，支持 Windows、macOS 本地编译，也可导入 Overleaf。

查看 GitHub 仓库 江南大学研究生院官方说明

2025 修订版

围绕江南大学研究生院 2025 年修订格式规范整理，保留论文结构、摘要、目录、正文、参考文献和附录示例。

本地编译优先

提供 Windows 和 macOS 的 TeX Live、MacTeX、TeXstudio、TeXShop 与 VS Code 编译说明，降低 Overleaf 大项目限制影响。

公开模板

仓库只包含占位示例和模板源码，不包含个人论文正文、实验数据、图表或个人成果信息。
