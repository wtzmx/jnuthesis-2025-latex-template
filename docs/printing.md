# 完整论文填写与打印

编译 `root.tex` 得到一份 `build/root.pdf`，无需再手动拼接封面、声明或委员会名单 PDF。源码仍按章节分文件维护，最终打印文件只有一份。

## 组成和填写位置

1. 封面：`setup/settings.tex`，填写中英文题目、作者、学位类型、分类号、专业、导师和授予年月。
2. 原创性声明及关于论文使用授权的说明：同一页，原文保存在 `preface/declaration.tex`，来自官方附件2。签名和日期均留空，按通知要求由作者、导师亲笔填写，不自动印上作者姓名充当签名。
3. 答辩委员会名单：`setup/committee.tex`，每个 `\jncommitteerow{职务}{姓名}{职称}{工作单位}` 对应一行；委员行可按实际情况增减。最后填写 `\jndefensedate`，例如 `\renewcommand{\jndefensedate}{2026年6月15日}`。默认保留附件3的主席、六行委员、秘书和答辩日期空栏。
4. 中文摘要、英文摘要、目录、正文、参考文献、可选附录、致谢、成果清单：继续在原有各章节文件填写。

声明标题按附件用三号黑体，正文用四号楷体。当前机器使用 Microsoft Word 自带的 KaiTi；附件中的旧名称是“楷体_GB2312”。如果需要指定旧字款，可自行提供 `fonts/kaiti_gb2312.ttf`。也支持 `fonts/simkai.ttf`、系统 KaiTi/KaiTi_GB2312；不随仓库分发商业字体。委员会表格按附件使用小四宋体，行高至少 1.5 cm，工作单位较长时允许换行。

声明和名单页保持各一页。若名单过长超出版心，编译会明确报错，避免把内容无声拆到本应空白的背面；请删去多余空行或精简单位名称后重编译。

## 编译

```sh
latexmk root.tex
```

## 单个 PDF 的双面打印

依据通知第四部分，封面、原创性声明页、答辩委员会组成页单面印刷，其余双面印刷。因此模板在前三张内容页后分别保留一张空白背面：

| PDF 物理页 | 内容 |
| --- | --- |
| 1 | 封面，无页码 |
| 2 | 封面空白背面 |
| 3 | 原创性声明及使用授权说明，无页码 |
| 4 | 声明空白背面 |
| 5 | 答辩委员会名单，无页码 |
| 6 | 名单空白背面 |
| 7 起 | 中文摘要从罗马数字 I 开始，之后连续排版 |

打印选择 **A4、实际大小（100%）、双面长边翻转**，保留 PDF 中的空白页，不进行小册子拼版。正文从右页及阿拉伯数字 1 开始，正文至末尾不人为插入空白页。

若印刷店另用较厚封面纸，可把物理第 1–2 页作为第一张纸分开处理，内芯从物理第 3 页开始保持原顺序双面打印。书脊需按实际纸张和装订厚度另行制作。

当前 PDF 虽然已经具有完整页面结构，但封面、名单及论文正文仍有空白或占位信息。打印正式版本前请填写真实信息，并完成规定的手写签名和日期。
