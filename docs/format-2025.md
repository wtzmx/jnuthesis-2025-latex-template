# 2025 格式规范修订说明

本次修订以 `参考/关于印发《江南大学研究生学位论文要求及格式规范（2025年修订）》的通知.pdf` 第 14–16 页为排版依据，并核对 `参考/Word版附件` 中五份附件。Word 附件仅作样式补充；与通知文字冲突的地方采用通知要求。

## 已实现的格式

| 项目 | 模板设置 |
| --- | --- |
| 纸张及版心 | A4，上下左右各 2.5 cm，页眉页脚在版心外 |
| 中文字体 | 宋体 SimSun；黑体 SimHei；二、三级标题用 SimSun 合成加粗 |
| 西文字体 | Times New Roman；数学拉丁字母与数字也用该字体，专用数学符号使用数学字体 |
| 章标题 | 三号黑体，16 磅，居中；章号采用“第 1 章” |
| 节标题 | 四号宋体加粗，14 磅，左对齐 |
| 小节标题 | 小四号宋体加粗，12 磅，左对齐 |
| 标题段距 | 章标题前后各 15.6 磅，节和小节前后各 7.8 磅；一行取 Word 附件的 312 twips |
| 正文及摘要 | 小四号，首行缩进两个汉字，1.25 倍行距 |
| 摘要、目录、致谢、附录标题 | 三号黑体，两字之间留两个汉字宽；英文摘要标题为三号 Times New Roman 加粗 |
| 关键词 | 另起段缩进两字，标签小四加粗，内容小四常规；中文分号与英文分号分别处理 |
| 目录 | 三级，小四宋体，固定 20 磅行距；左缩进依次为 0、2、4 个字符 |
| 图表 | 图题在下、表题在上，五号居中；tabular、tabularx、longtable 内容五号 |
| 参考文献 | 五号、1.25 倍行距；取消旧样式每条文献末尾的负间距，字号不影响后续章节 |
| 页眉 | 奇数页为章序及标题，偶数页为学校及学位论文名称，五号宋体居中 |
| 页脚 | 前置部分连续大写罗马数字；正文至末尾连续阿拉伯数字，五号居中 |
| 分页 | 正文第一页从右页开始，此后各章仅另起一页，不强制奇数页、不插入空白页 |
| 附录 | `\jnappendix` 后用 `\chapter`；按 A、B 编号，公式与图表使用 A-1 等编号 |

LaTeX 的 `\setstretch{1.25}` 是相对于其单倍基线的倍数。本机正文实测基线间距为 18 磅；目录实测为固定 20 磅。Word 的自动行距受字体度量、文档网格和版本影响，因此不保证逐行换行及分页与 Word 完全相同。若学院要求某个固定基线值，应另外明确设置，不使用猜测的 1.35 倍行距。

## 字体与编译

字体集中在 `setup/fonts.tex`。查找顺序是：

1. 用户自行提供的 `fonts/simsun.ttc` 和 `fonts/simhei.ttf`。
2. macOS Microsoft Word 应用内的同名字体。
3. 系统中安装的 SimSun 和 SimHei。

找不到上述字体时编译报错，不静默降级到 Fandol。字体文件不随仓库分发，`fonts/` 下的字体文件已加入 Git 忽略规则。Windows 通常可以直接找到系统字体；Overleaf 需要用户在许可允许的情况下自行提供字体，并确保 Times New Roman 可用。

采用 XeLaTeX 编译：

```sh
latexmk root.tex
```

标题由 CTEX 统一管理，不再混用 titlesec。`amsmath` 已由文档类加载，不要在 `mathspec` 之后重复加载；数学字体设置见 `setup/fonts.tex`。

## 附件差异和提交前事项

- Word 附件 1 及附件 4 英文摘要所在节的上下边距是 2 cm，通知第 16 页要求四边 2.5 cm，本模板采用 2.5 cm。
- Word 目录样例有 `Absract` 拼写错误及手工缩进差异；采用正确的 `Abstract` 和通知规定的两字、四字缩进。
- 封面、原创性声明和使用授权说明、答辩委员会页均由 LaTeX 自动生成并合入 `build/root.pdf`。声明保留官方原文和手写签名、日期空位；名单在 `setup/committee.tex` 填写。参见 [完整论文打印说明](printing.md)。当前仍有待填写项和论文占位正文，不能不经填写就提交。书脊按实际装订厚度另行制作。
- 封面、声明页、答辩委员会页的背面均保留空白以单面印刷，摘要从右页开始；正文起始前也可能有一张用于双面印刷的空白页。正文至结尾没有人为插入空白页。
- 中文摘要通常为 800–1000 字，关键词 3–8 个。现有正文与摘要仍是占位内容，未代写论文。
- 参考文献继续使用现有 `jn.bst` 的引用顺序、前三名作者及文献类型逻辑；具体条目是否完整、准确仍需按实际文献核对。
- 盲审版应按通知隐去有关作者和导师的信息、成果名称，并移除致谢。此修订未自行修改作者身份信息或生成盲审版本。
- 通知同时要求 Word 和 PDF 电子版；本项目产生 LaTeX 源码及 PDF，未生成论文 Word 正文版本。
