# 发布说明

版本号在根目录 `VERSION` 中维护；发布前同步更新 README、CHANGELOG 和文档类版本标记。当前为 0.4.0。

运行 `python3 scripts/release.py`，脚本会调用 latexmk 完成编译，并在 `dist/` 中生成 ZIP 和对应的 `.zip.sha256` 校验文件。压缩包内部附 `MANIFEST.sha256`，可校验每个打包文件。脚本不提交 Git、不打标签、不推送仓库，也不创建 GitHub Release。

发布包包括：模板源码、配置、示例正文、字体准备说明、项目文档、学校通知 PDF、五份 Word 附件、学校校名字样以及编译得到的 `example.pdf`。不包括商业字体、`.git/`、编译中间文件、旧版本发布包或本机路径配置。

学校参考文件保持原名和原内容，并通过打包清单记录校验值。用户填写过真实姓名、委员信息或正式论文内容的工作副本，不应作为公开模板发布；发布脚本不会自动替换这些内容。

本次发布准备在 macOS / TeX Live 2026 上验证；Windows 和 Overleaf 使用同一套 XeLaTeX 源码，但仍需在目标环境提供对应字体。文件格式一致不代表已经完成跨平台实测。

发布前复核：构建成功、示例 PDF 页面完整、空白背面与页码正确、源码仅含模板占位内容，ZIP 内含六份学校参考文件且不含字体文件。
